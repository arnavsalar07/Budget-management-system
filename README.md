# Budget-management-system

## Description

The Budget Management System is a console-based application developed in C using file handling concepts. This project helps users track their expenses against a predefined budget. Users can set a fixed budget amount, record their expenses, and monitor their remaining balance in real time.

The application stores all expense records in files, ensuring that data is preserved even after the program is closed. By utilizing file handling techniques, the system provides a simple and efficient way to manage personal finances through a command-line interface.

This project was developed to strengthen programming fundamentals in C, particularly in the areas of file handling, functions, structures, and data management. It demonstrates how real-world problems such as budget tracking can be solved using basic programming concepts.

## Features

* Set and manage a fixed budget.
* Record daily expenses.
* Automatically calculate total spending.
* Display the remaining budget balance.
* Store expense records permanently using file handling.
* View saved expense history.
* Simple and user-friendly menu-driven interface.

## Technologies Used

* Programming Language: C
* Concepts: File Handling, Structures, Functions, Arrays, Loops, Conditional Statements
* Storage: Text Files
* Application Type: Console-Based Application

## Objectives

The main objective of this project is to help users monitor their spending habits and stay within their budget limits. It also serves as a practical implementation of file handling and data management concepts in C programming.
